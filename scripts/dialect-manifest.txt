# Dialect manifest: the source of truth for which packages run on PostgreSQL and MySQL.
#
#   sensitive   runs every test on SQLite, PostgreSQL and MySQL. Use it when a
#               test's outcome can depend on the SQL dialect.
#   sqlite-only runs on SQLite only (and in the weekly full run).
#
# Every package from `go list ./...` must appear exactly once;
# scripts/dialect-packages.sh fails on a missing or stale entry. Classify a
# package, not a test: inside a sensitive package, a test that does not depend
# on the dialect calls testdb.SQLiteOnly(t, reason).
